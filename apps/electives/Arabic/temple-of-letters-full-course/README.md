## Privacy and operation

The course does not transmit learner answers or progress. Saved progress remains in the browser's local storage. The page contains no analytics, advertising, accounts, remote fonts, remote audio, or required network calls.

Speech uses the device's installed Arabic text-to-speech voice when available. Voice quality and pronunciation therefore vary by operating system and browser.
