# French 101 — Learning Video Assets

This folder is the **canonical candidate library** for French 101 learning videos and related audio/exercise references.

- `catalog.json` contains **four source-page-verified video candidates** and **two additional non-video learning references** for Unit 01.
- No video files have been copied, downloaded, mirrored or embedded. Third-party media must not be stored here unless its redistribution rights are explicitly verified.
- All items are `CANDIDATE`, **not approved for students**. Review video-specific ratings (if available), full media content, educator quality, live playback, advertisements, accessibility and licensing before promoting to lessons.
- `video_specific_rating:null` and `review_count:null` mean **not independently verified**; never substitute the app's public rating for a particular clip.
- The Academy's core lesson, audio practice and assessment must continue to work if these links go offline.
- All source pages were checked on October 28, 2026, but actual player playback and live browser certification remain outstanding.
- Promotion instructions: [Video Promotion Policy](../../docs/FRENCH_101_VIDEO_PROMOTION_POLICY.md).

## Intended structure
After educator approval, lesson code can read the catalog or link to an approved item using its stable `id`. Do not promote these links automatically.

Keep future original Academy-produced media in a separately licensed subfolder with attribution and transcript, rather than mixing it with third-party catalog entries.
