Five Complete Language Programs

Choose a language, then enter at the right level.

The World Atlas remains open to 206 languages and language concepts. These five receive full middle-school, high-school and lower-division college course ladders in V4. American Sign Language remains in the Atlas and is the priority sixth full program.

Formal Course Workspace

Thirty-six-week school courses and sixteen-week collegiate courses.

Each course develops interpretive, interpersonal and presentational communication alongside language control, script/pronunciation, culture, mediation, research and portfolio evidence.

Eleven Permanent Competencies

Language ability is not one percentage.

Track each competency separately for the current language and course. “Secure” is a Khaemenes learning record, not an official ACTFL, CEFR or external exam rating.

Performance Practice Studio

Practice what the course actually asks you to do.

These prompts are generated from the current language and course themes. They create portfolio evidence rather than pretending that multiple-choice recall alone is language proficiency.

Performance-Based Assessment

Interpret · interact · present · revise.

Use this chamber to record evidence from listening, reading, interpersonal exchange, speaking and writing. Knowledge checks support learning, but course completion requires performance evidence.

Preserved V3 Foundation Library

All forty original language-learning modules remain available.

They now function as a cross-language foundations library rather than the one mandatory curriculum for every language.

World Language Atlas

206 dossiers remain open beyond the five full programs.

Signed, classical, heritage, Indigenous, endangered and world languages remain visible so the Academy does not confuse “five complete pathways” with “five languages worth learning.”

Source Vault · 53 Gateways

General frameworks plus language-specific authoritative pathways.

Advanced work should add current community, teacher, university, corpus, archive and language-specific sources rather than rely on one generic phrase site.

Language Vault V4

One learner can study several languages without overwriting progress.

V4 stores progress by language → course → competencies / assessments / portfolio. Existing V3 data is preserved as a legacy snapshot and can inform the new profile without automatically awarding course completion.
